# Student Pack — Expanded CTI Investigation Lab

**Case:** Password Spraying and Account Takeover  
**Level:** Beginner / early intermediate  
**Suggested time:** 2 hours  
**Team size:** 3–4

## Start here
1. Read `01-Incident-Brief.md`.
2. Examine `02-Evidence-Packet.md` and `03-IOC-and-Context-Sheet.csv`.
3. Use `04-Research-Links.md` for Task 4.
4. Complete `05-Student-Worksheet.docx`.

## Important
The original case narrative is adapted from Incident 2 in the CTI Analyst Challenge. To make the exercise suitable for a longer practical, the additional timestamps, sign-in records, MFA events, SharePoint audit events, IP addresses, domain names and competing activity are **synthetic training data created for this exercise**. They are not real indicators and must not be used as real-world threat intelligence.

Use only the supplied evidence. Distinguish facts, interpretations and unknowns. Do not invent missing details or attribute the activity to a named threat actor.
