# Student Pack — CTI Practical

## Start here
1. Read `01-Incident-Brief.md`.
2. Review `02-Supporting-Evidence-Cards.md`.
3. Use `03-Research-Links.md`.
4. Complete `04-Student-Worksheet.docx`.

**Team size:** 3–4 students. **Duration:** approximately 2 hours. No specialist software is required.

Do not invent timestamps, IP addresses, logs or threat actor identities. Separate facts from assumptions.

## Source and adaptation
Adapted for classroom use from Incident 2 in the CTI Analyst Challenge:
https://github.com/BushidoUK/CTI-Analyst-Challenge/blob/main/Demos/DemoIncidentArtifacts.md

The original is a short narrative, not raw telemetry. Evidence cards reorganise stated facts and do not add fabricated logs. This independent educational adaptation is not affiliated with the repository authors.
